# Мой пробег — версия 1.3

Приложение для Android и iPhone. Учитывает ежедневный пробег и стоимость топлива. При распознавании одометра цифры нужно проверять вручную.

## Что изменилось

**В настройках → Топливо и цена** теперь доступны два варианта:

1. **Вводить вручную** — стоимость за литр указываете самостоятельно.
2. **Автоматически по сети АЗС** — выбираете сеть и вид топлива, нажимаете «Сохранить настройки». Приложение пытается получить региональную цену через серверную функцию и обновлять её при открытии приложения (проверка не чаще раза в 6 часов). Можно нажать «Обновить цену сейчас». В поле цены по-прежнему разрешено ручное исправление.

Сети: ОККО, WOG, UPG, UKRNAFTA, БРСМ-Нафта, AMIC, Parallel, Mango, Neftek, RLS, VST, VostokGaz и ДНІПРОНАФТА.

Типы топлива: А-95+, А-95, А-92, дизель и газ LPG. **Не все сети предлагают все виды топлива**. Если по комбинации нет цены, программа её не выдумывает.

Источник: [Минфин — Днепропетровская область](https://index.minfin.com.ua/markets/fuel/reg/dnepropetrovskaya/), данные консалтинговой группы А-95. Это **региональные цены сети**, а не гарантированная цена конкретной АЗС. Данные могут быть устаревшими, а обновления источника — нерегулярными. Неофициальный источник; доступность автоматической функции зависит от структуры его страницы.

## Самый простой старт — только ручной ввод

1. Распакуйте ZIP.
2. Для простого сайта можно разместить `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest` и папку `icons` на HTTPS-хостинге, например через Netlify Drop.
3. Откройте ссылку на телефоне. На Android: Chrome → «Установить»; на iPhone: Safari → Поделиться → «На экран Домой».

**Важно:** ручной режим работает на простом статическом хостинге, но автообновление цен **не будет работать**, поскольку требуется серверная функция. Не стоит ожидать автоцен от загрузки папки через Netlify Drop.

## Как включить настоящие автоцены

Для этого проект нужно публиковать через репозиторий GitHub, подключённый к Netlify (Git-based deploy), а не через простую загрузку файлов.

1. Создайте пустой репозиторий на GitHub.
2. Загрузите **содержимое папки `odometer-pwa`** в корень репозитория (важно, чтобы файл `netlify.toml` был в корне).
3. В Netlify выберите **Add new project → Import an existing project** (названия кнопок могут немного отличаться).
4. Подключите GitHub и выберите репозиторий. Netlify прочитает `netlify.toml`, установит зависимость `cheerio` и развернёт функцию `/.netlify/functions/fuel-prices`.
5. После публикации откройте сайт, перейдите в «Настройки», выберите автоматический режим, сеть АЗС, вид топлива, сохраните и обновите цену.

Если серверный источник недоступен, появится предупреждение. Ручной ввод продолжит работать. При сбое данные поездок не теряются, а предыдущие записи не пересчитываются.

## Защита данных

Все поездки хранятся **локально на телефоне**, не передаются на сервер цен и не синхронизируются между устройствами. Делайте резервные копии через раздел «Настройки» → JSON.

## Технические сведения

- Офлайн-журнал реализован на HTML/CSS/JS и Service Worker.
- Режим автоцен: Netlify Function (`netlify/functions/fuel-prices.cjs`) получает HTML источника на сервере и извлекает опубликованные региональные значения. Изменение формата сайта может временно сломать автоцену.
- Доступные виды топлива отображаются в меню всегда; отсутствие цены обозначается явно.
- OCR: Tesseract.js; первая загрузка движка требует интернет.
- Данные из предыдущей версии 1.0 остаются в хранилище того же адреса сайта/браузера. Резервная копия JSON 1.0 импортируется.
- Это PWA, а не APK/IPA из магазинов приложений.

## Версия 1.2 — фирменные названия топлива

Выбор станции автоматически меняет список топлива. Проверенные названия: OKKO (PULLS 95, PULLS 100, PULLS Diesel), WOG (Mustang 95/100, ДП Mustang+), UPG (upg95, upg100, upgDIESEL), UKRNAFTA (ENERGY 95, ENERGY ДП). Для остальных сетей пока остаются общие классы топлива: их собственные марки не выдуманы. Наличие конкретной марки на отдельной станции не гарантируется.

Цены источника относятся к общим колонкам А-95+, А-95, А-92, ДТ, LPG. Если отдельной цены для марки нет (например, 100-й бензин или премиальный дизель), указывайте стоимость вручную. Старые записи сохраняются.

**Как установить обновление на существующий сайт:** на GitHub откройте свой репозиторий, загрузите новые файлы из содержимого папки `odometer-pwa` (включая папку `netlify` и `netlify.toml`) с заменой старых. После нового deploy в Netlify обновите сайт в браузере два раза. Для серверной функции проверьте, что файл `netlify/functions/fuel-prices.cjs` присутствует в GitHub, а в Netlify функция появилась в разделе Functions. Если функции нет, проблема в настройке сборки/развёртывания, а не в выборе топлива.


## Версия 1.3 — точность и прозрачность цен

- Показывает ссылку на источник (Минфин), дату публикации цены (если указана) и время, когда данные получены сервером.
- Цены по общим категориям топлива показаны только как **региональный ориентир**, а не стоимость отдельной колонки.
- Для фирменных видов (PULLS, Mustang, upg, ENERGY) приложение **не подставляет** цены общего А-95+ или дизеля: при отсутствии официально сопоставленной отдельной цены просит ручной ввод.
- Сервер отбрасывает явно ошибочные строки, например если цена дизеля ошибочно попала в графу LPG. При недостатке проверенных данных автообновление не сработает; ручной ввод остаётся доступным.
- Предыдущие поездки остаются на том же сайте и устройстве. На всякий случай перед обновлением сделайте резервную копию: Настройки → Скачать копию JSON.

### Как обновить уже опубликованное приложение

1. Распакуйте архив `my-mileage-pwa-v1.3.zip`.
2. Откройте GitHub → репозиторий `my-mileage` → Add file → Upload files.
3. Перетащите **содержимое** папки `odometer-pwa`, включая вложенные папки `netlify`, `tests` и `icons`.
4. Нажмите Commit changes. Дождитесь статуса Published в Netlify → Deploys.
5. На странице приложения нажмите Ctrl+Shift+R на компьютере или перезагрузите страницу на телефоне. Откройте Настройки → Топливо и цена.

**Ограничение:** полноценной автоматической цены по каждому фирменному виду топлива сейчас нет: доступный региональный источник публикует общие категории, а не раздельные фирменные марки. Мы не можем безопасно выдать цену общего А-95+ за PULLS 95 или аналог. Для точных марок используйте ручной ввод до подключения проверенного источника.
