Топливо и цена

Цена ещё не загружена.

Показана средняя цена по сети в Днепропетровской области, а не цена конкретной колонки. Скидки и карты лояльности не учитываются. Данные предоставлены агрегатором, могут запаздывать.

Новая цена применяется только к новым записям. Старые поездки не пересчитываются. Без интернета можно ввести цену вручную.

Резервная копия

Данные находятся только в этом браузере на этом устройстве. При его очистке записи могут пропасть — регулярно сохраняйте копию.

Установка и работа без сети

Откройте приложение по HTTPS. На Android выберите «Установить приложение» в меню браузера; на iPhone — «Поделиться» → «На экран Домой». После первого открытия журнал доступен без сети. Для распознавания фото интернет необходим.

РАСПОЗНАВАНИЕ

Фото одометра

Сфотографируйте показания одометра, затем выделите цифры рамкой. Не включайте скорость, запас хода и суточный пробег.

Проведите пальцем по фото, чтобы выделить область с показаниями.

Распознавание работает через Tesseract.js; при первой загрузке требуется интернет. Фото не отправляется на сервер приложения, но библиотека загружается из внешнего CDN.
